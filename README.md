# Python-Data-Analysis-Assignment-1-Numpy-and-Pandas

## Project Overview

This project is part of my Python Data Analytics learning journey. The main objective of this assignment is to understand how NumPy and Pandas work and how they can be used to perform basic data analysis using Python.

Through this assignment, I worked with temperature data, student marks, and transaction details to practise creating arrays, exploring datasets, filtering information, and performing basic calculations.

## Topics Covered

### 1. NumPy – Array Operations

In this section, I worked with daily temperature data recorded over two weeks.

**Tasks performed:**
- Created 1D and 2D NumPy arrays.
- Checked array shape, data type, and number of elements.
- Converted temperatures from Celsius to Fahrenheit.
- Calculated maximum, minimum, and mean temperatures.
- Practised array indexing and slicing.
- Extracted temperatures for weekdays, weekends, and individual weeks.

### 2. Pandas – Series Operations

In this section, I created a Pandas Series using student marks with custom index labels.

**Tasks performed:**
- Created a Series with custom indices.
- Accessed values using integer positions.
- Used `loc` and `iloc` for indexing.
- Applied Boolean filtering to find marks greater than 90.
- Modified and removed Series entries.
- Calculated CGPA by dividing marks by 10.

### 3. Pandas – DataFrame Operations

In this section, I worked with a transaction dataset containing transaction IDs, product categories, regions, and amounts.

**Tasks performed:**
- Created a Pandas DataFrame.
- Explored data using `head()`, `tail()`, `shape`, `columns`, `dtypes`, and `info()`.
- Selected specific columns and rows.
- Applied conditional filtering.
- Used `value_counts()` and `unique()`.
- Grouped transactions by region and calculated the average amount.
- Updated existing values and created a new Discount column.
- Removed specific rows and columns.

## Key Learnings

While completing this assignment, I gained practical experience in working with NumPy arrays, Pandas Series, and DataFrames. I also learned how to explore datasets, select and filter data, perform calculations, and manipulate data using simple Python commands.

This assignment helped me build a stronger foundation in Python for Data Analytics.

## Conclusion

This was a useful hands-on learning experience that helped me understand the basics of data analysis using NumPy and Pandas. I look forward to applying these concepts in more practical data analytics projects.
